# 🧠 About Logic Box

**Logic Box** is a Python-based learning project designed to improve programming logic and problem-solving skills.

It helps beginners understand how to think like a programmer through:
- 🧩 Logic building
- 🐍 Python practice
- 🔢 Problem solving
- 💻 Coding challenges
